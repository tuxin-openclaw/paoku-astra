# PAWS OUT · 橘猫逃离办公室

React + Vite + Three.js 制作的可游玩 3D 无限跑酷。所有角色和办公室模型由代码生成，无需下载游戏美术资源。

[在线游玩](https://tuxin-openclaw.github.io/paoku-astra/) · [GitHub 仓库](https://github.com/tuxin-openclaw/paoku-astra)

## 部署

推送到 `main` 后，GitHub Actions 会自动安装依赖、执行测试、构建并部署到 GitHub Pages。部署记录见仓库的 Actions 页面。

CI 构建使用 `/paoku-astra/` 资源前缀，本地开发保持 `/`。无需配置部署密钥。

## 启动

```sh
npm install
npm run dev
```

打开终端显示的本地地址（默认 http://localhost:5173）。同一 Wi-Fi 的手机可使用终端 Network 地址。

```sh
npm test       # 物理、碰撞、生成规则测试
npm run build # 生产构建，产物位于 dist/
npm run preview
```

## 玩法

- 左右方向键或 A / D 换道；上方向键、W 或空格跳跃。
- 手机左右滑动换道，上滑或轻触画面跳跃，也可使用底部触屏按钮。
- ESC / P 暂停或继续；空格可开始、重开或继续。
- 纸箱与办公椅可跳过，高推车必须换道。每组障碍至少保留一条安全路线。
- 每米 1 分，小鱼每条 25 分。速度由 10 m/s 逐渐升至 23 m/s。
- 碰撞后结束，可立即重开；最佳分保存在当前浏览器。
- 离开浏览器标签页自动暂停；支持音效开关与全屏。

## 实现

`src/game.js` 为独立的游戏逻辑，采用最多 1/120 秒的物理子步避免穿透。`src/scene.js` 负责模型、灯光、阴影、循环场景、动画和粒子；`src/main.jsx` 负责界面、输入与生命周期；`src/audio.js` 使用 Web Audio 合成音效。

没有后端、账号或外部游戏素材依赖。字体使用 Google Fonts 并提供系统字体回退。需浏览器支持 WebGL；移动端实际帧率取决于设备性能。开发环境提供只读 `window.__PAWS_DEBUG__()` 供调试，生产环境不暴露。

## 已完成的验证

- 12 项 Node 测试通过，包括碰撞、跳跃、换道边界、计分、暂停、重开、速度上限、1000 组随机障碍通路和十分钟逻辑模拟。
- Vite 生产构建通过。
- Chrome 实际浏览器检查：启动、键盘换道与跳跃、小鱼收集、暂停与继续、碰撞结算、失败重开、最佳分刷新后保留、静音开关与全屏。
- 390 × 844 手机视口检查：触屏按钮、布局、说明与结算弹窗、开始后的页面定位。已修复发现的弹窗裁切与滚动偏移。
- 未使用实体手机测试；iOS Safari、Android 真机性能和实际扬声器音效尚未验证。

当前开发服务使用 `http://127.0.0.1:5186/`（默认 5173 端口与本机其他服务冲突）。重新启动可运行 `npm run dev -- --port 5186 --strictPort`。
